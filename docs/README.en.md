# Media Downloader

Free desktop and Android media downloader by Alex Ascencio. [Website and packages](https://mediadownloader-blush.vercel.app) · [Releases](https://github.com/Bielicoman/mediadownloader/releases).

Install the Windows Desktop first, then the Adobe panel or Editors companion if needed. Paste an authorized link, choose the output folder and format, and download. Playlist links can open the full playlist or just the current video. Lists support item selection, list/grid views and thumbnail sizing.

Choose **Language** in Settings, or in the website/companion header. Additional translations are Beta; source media titles, file paths and engine logs remain unchanged.

Adobe, Resolve, CapCut, Avid, Final Cut, Android and older Mac/Linux packages are labeled Beta where applicable. The Editors tool is external to CapCut/Avid/Final Cut. The public browser downloader is disabled; the website hero is an explicitly labeled simulation.

Unknown publisher warnings can occur because Windows packages lack a commercial publisher certificate and Mac packages are not notarized. Verify the source and integrity first. Do not disable antivirus or ignore a malware detection. Follow the official per-file controls offered by Windows/macOS; on Android allow only the installer source you trust and keep Play Protect enabled. [Detailed installation notice](AVISOS-DE-INSTALACAO.md).

Windows application updates install on exit after media downloads finish. Adobe verifies the update ZIP and keeps a backup. Android requires OS confirmation. Mac/Linux and portable packages use manual updates.
