Antes de pedir ajuda

  1. Confira o formato e a pasta selecionados.
  2. Abra Configurações e veja se yt-dlp e FFmpeg estão prontos.
  3. Se a fonte mudou ou o download falhou, atualize o yt-dlp pelo botão do aplicativo.
  4. Para o painel, confirme se o Desktop está instalado e se o Premiere foi reiniciado após instalar o plugin.

O que enviar

Informe o sistema operacional, a versão do aplicativo, a mensagem de erro e os passos para reproduzir. Se o link não for privado, você pode enviá-lo. Não envie cookies.txt, tokens, senhas, dados de conta ou projetos privados. Remova essas informações de capturas de tela.

Downloads e instalação

O guia por sistema informa o arquivo correto e a versão publicada. No Windows, a opção padrão é instalar apenas no usuário atual. O painel do Premiere tem instaladores próprios no ZIP.

Privacidade, direitos e segurança

Para solicitações de dados pessoais, consulte a Política de Privacidade. Para comunicar uma vulnerabilidade, envie detalhes pelo e-mail, sem divulgar credenciais ou dados de outras pessoas.
