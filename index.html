Passo 03 · O macOS vai bloquear na primeira abertura

Vai aparecer “O item Media Downloader não foi aberto”, dizendo que a Apple não pôde verificar o app. Isso é esperado e não significa que o app esteja danificado — ele só não passou pela notarização paga da Apple. O botão OK é a única opção do aviso; o desbloqueio fica nos Ajustes:

  1. Clique em OK para fechar o aviso.
  2. Abra Ajustes do Sistema › Privacidade e Segurança.
  3. Role até o fim: vai haver a linha “Media Downloader foi bloqueado” com o botão Abrir Assim Mesmo.
  4. Confirme com Touch ID ou senha e clique em Abrir. Só é preciso fazer isso uma vez.
Alternativa pelo Terminal · resolve de uma vez
xattr -dr com.apple.quarantine "/Applications/Media Downloader.app"
04

Pronto! Abra pelo Launchpad ou Spotlight.

yt-dlp, FFmpeg e ffprobe já vêm integrados dentro do pacote — sem Homebrew, sem terminal.
